- 板型 sf32lb52-lchspi-ulp，SDK v2.5.1，RT-Thread；串口监视采用 1000000 baud。
- 修改入口为 src/main.c；原始基线为 b3b2024（v0.1.0 / Hello world!）。
- 可用日志或截图核对这项文字需求；不能以编译成功替代真实启动证据。
- 保存实际构建日志、下载结果、启动原始日志和对应 Git 提交。
- REQ-001的v0.1.1结论只覆盖串口文字；新增REQ-002未实测前不记屏幕通过。本练习不代表T1按键任务或正式产品完成。

前面REQ-001/002及其版本证据保持历史范围。训练指南中的示例编号已被历史练习使用，本次顺延为REQ-003/004，功能与判据不减少。负责人王焕博；从现有v0.1.2创建feat/t1-key-rgb分支，目标首版v0.2.0。

KEY1为引脚34、高电平有效；KEY1同时有电源/下载用途，真机测试使用短按、释放，不测试长按关机。保留屏幕页，显示本版版本与T1提示，不新增触摸、联网或其他外设功能。5ms是请求的采样等待周期，不是已经测得的端到端响应时间。

第一版按训练要求只检测原始电平边沿，不加消抖。这是待检验的实现策略，REQ-004判据保持不变。若测试暴露抖动，先登记缺陷、更新设计，再修复并重测；若未复现，也如实写未复现和风险。
