# ADR-0015 现实作息与手机校时

2026-11-08登记。状态：方向已采纳；2026-11-08 v0.14.0现实钟/手动校时/昼夜作息软件已实现，板端待测。

用户在iPhone连接及PING/PONG验证后，明确选择“按现实时间作息，接入手机校时”。备选是继续30分钟一日、另外显示现实钟，或暂不改时间只做连接与声音。现实作息更适合持续陪伴，但需要有效时间来源；加速更容易短时间看到完整一天，亦与现实作息脱离。用户选择前者。

本决定替代ADR-0014中48倍作为主世界时钟及关机暂停日历的部分。旧决定保留历史，未实现的旧测试改为新要求后再执行。现实钟由RTC读取，手机通过明确校时操作设置；连接本身不带入iPhone时间。首版北京时间UTC+8。未校时或RTC失效提示待校准，不用启动默认日期假装已同步。

离线策略区分两类时间：日历和昼夜随有效RTC继续；饱食/心情、外卖/冷却、动作、音频和奖励仅随实际运行时间推进，关机不补算惩罚和收益。调时不能跳过动作、补奖励、重复结算或拖坏保存节流。断电保时只能据硬件实测确认。

REQ-191至REQ-195按此更新；新增校时、连接显示、音量、睡眠、游戏和资源约束见REQ-199至REQ-205与pet-revision-plan.md。具体窗口和参数由AI拟定，用户选定的是现实作息和手机校时方向。

实施落点：0004为14字节本地UTC+8日期时间，范围2024–2037，主线程RTC设置/读回，格式7只存资格标记；操作与板测边界见pet-v014-clock.md。自动手机发送器仍属后续集成。
