# ADR-0014 加速24小时校园作息

2026-11-07。已采纳：流速、关机暂停、按时段保留替代活动。实现与保存布局尚未完成。

用户提出按现实24小时作息组织活动，但让时间更快。在现实15、30、60分钟分别对应游戏一天的方案中，用户选择“现实30分钟＝游戏一天”，即48倍。15分钟变化更快但路上更易跨时段；60分钟更从容但一次体验更长，30分钟作为首个平衡点。

关机暂停与离线继续两方案中，用户选择关机暂停、开机继续；因此恢复最后保存的日程，不依赖现实日期补算。活动约束比较仅提醒、严格开放和按时段保留替代活动，用户选择后者。

实施方向：独立日程钟驱动作息和昼夜，走路、动画、小游戏展示、PCM和保存节流继续用实际运行时间；只保留饱食/心情。具体07:00起点、课程和餐点时间窗、被动变化参数由AI拟定，见pet-time-system.md，不冒充用户逐项指定。

记录天数和时刻需要保存布局评审，64字节重排或扩展记录尚未选择，不在本ADR预设结论。REQ-191、REQ-192、REQ-193、REQ-194、REQ-195；TC-203至TC-210均尚未执行。
