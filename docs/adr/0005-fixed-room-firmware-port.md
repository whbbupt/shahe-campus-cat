# ADR-0005：固定房间方案移植延续纯C单所有者

日期2026-10-26。用户明确授权把网页v1.4接入手表固件，沿用ADR-0003的模型/UI边界，不新增硬件、线程或服务。

| 方案 | 收益 | 代价 |
|---|---|---|
| A：在LVGL回调和动画里等待移动再直接改数值 | 初始代码较少 | 重选、重建、打断容易重复结算，规则难独立验证 |
| B：纯C世界模型拥有路径/意图/时钟/结算，LVGL只读快照 | 可共享自检、重选/冷却可复现，继承原分层 | 需补有界图和状态机 |

按用户移植授权延续既有B边界；具体常规实现由AI完成，不冒充学生重新选择每个技术细节。新模型与原模型分别保留，原训练和证据不覆盖。资源编译成ROM常量、两种中文子集随程序，避免改SDK/构建配置；物理验证仍由学生完成。
