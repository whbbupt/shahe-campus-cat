# ADR-0006：宠物专用Flash双份校验存档

日期：2026-10-28。

| 方案 | 优点 | 代价 |
|---|---|---|
| A：专用区域＋双份校验追加记录 | 小数据路径短、无文件系统、可故障注入、旧记录在新记录完成前保留 | 需专用分区、格式与擦写管理 |
| B：启用文件系统存文件 | 未来多文件扩展便利 | 新增配置/挂载/空间管理，不可照例程自动格式化已有数据 |

用户明确选择A，原话“A：专用区域＋双份校验存档（推荐）”。应用仍单所有者；存档状态机与驱动分离。不占用dfu/ble/fs现有区域，项目局部分区新增专用8KB；原SDK及构建骨架不改。64B追加槽用于降低擦除频次，轮流在两个4KB单元写入，提交标记最后写。自动保存稳定3秒、10秒最小间隔/失败重试、60秒计时余量检查点由AI按常规实现授权提出。重启从最后成功快照恢复，不做离线时间模拟，不重放进行中的业务；这些限制在运行说明和状态面板中体现。
