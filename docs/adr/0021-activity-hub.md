# ADR-0021: 活动中心弹窗 + 餐厅窗口标签 + 即时活动

- 状态：已采纳
- 日期：2026-11-10
- 决策人：王焕博（四选一确认）
- 关联需求：REQ-224–228

## 背景

用户提供北邮沙河校区示意图，要求保留原功能，按示意图更新外层校园；健身房保留但必须先进入学生活动中心；餐厅分窗口；学院勤工俭学；活动中心可跳舞/打羽毛球。现有代码只有 4 个可进入场景（宿舍/教室/食堂/健身房），道路图 1400×1300 已与示意图的主路网大致对应。

## 备选方案

| 方案 | 地图 | 活动中心/餐厅 | 活动 | 代价 |
|---|---|---|---|---|
| A. 保留底图叠加 + 弹窗/标签 + 即时交互 | 现有道路+建筑图上加名称、黄条施工区 | 活动中心弹窗三键；餐厅菜单 4 个窗口标签 | 即时 + 冷却/收益 | 最小改动，无新场景/存档格式；活动无动画 |
| B. 重绘扁平地图 + 新活动中心场景 + 独立餐厅楼 | 重画底图/建筑/门位 | 新场景、多建筑、多菜单 | 新动作/动画 | 视觉更贴近示意图，但道路/门/存档/测试回归大，周期长 |
| C. 只加活动中心弹窗，不做地图/餐厅/勤工俭学 | 原图 | 弹窗 | 即时 | 不满足用户本次大部分要求 |

## 决策

选择 **A**：

- 地图保留现有 1400×1300 道路与建筑资产，叠加建筑名称、黄色施工区与“施工重地 禁止进入”；不重画底图。
- 活动中心用**弹窗**：校园点“学生活动中心”先出现“去健身房/跳舞/打羽毛球”，健身房再走原 `PW_ENTER_GYM`。
- 餐厅用**菜单窗口标签**：全部保留原六道；风味/教工/学生各两道；只改界面过滤，不改模型/存档。
- 勤工俭学/跳舞/羽毛球用**即时交互+冷却**，复用现有 cooldown 槽，不新增动作枚举、不改存档格式 11。

## 后果

- 正面：兼容旧档/旧测试，能在 390×450 上快速完成；健身房仍保留但入口符合用户要求。
- 负面：活动没有动作动画；地图是“示意图叠加”而非重绘；施工区靠视觉+道路不可达，没有新增碰撞体；勤工俭学收益为平衡初稿。
- 后续若要动画/新场景，另立 REQ 与 ADR，不混入本版。
