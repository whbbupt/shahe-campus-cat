# ADR-0018 场景点餐与夜间宿舍生活

2026-11-09。用户否定集中商店、通关金币宣传，要求宵禁及更多餐食品类、实物布置；随后在“保留金币并场景点单”和“取消金币免费互动”两选项中明确选择前者，并确认23至06点宵禁/签到迁移/两处六菜品/宿舍布置范围。实施中进一步明确先坐下再弹可滑动买饭菜单、菜品图和数值平衡。

采用：金币仍是生活费，食堂坐席、宿舍手机分别选餐确认；签到移状态页，原固定位置三布置移入宿舍收纳箱入口。小游戏保留实际结算，只移除提前奖励宣传。夜间可叫醒和室内活动，禁止离开宿舍，在外仍可回家。具体菜价/营养、摸摸3与10秒冷却、课堂4/自习3/代码3/健身6为AI平衡参数，未冒充用户逐项指定。

复用模型/LVGL/RTC/自动保存，订单品类通过64字节记录的订单字段高16位编码，格式10读1至9，旧版保护拒写；保持分区/双区/驱动与节流。未新增拖拽布置或新硬件架构。真实画面、声音、流畅度与体验仍由用户本机验证。原话见evidence/pet/life_revision_20261109_user.txt。
