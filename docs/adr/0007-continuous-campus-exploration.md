# ADR-0007：连续校园地图与跟随镜头

日期：2026-10-28。

| 方案 | 优点 | 代价 |
|---|---|---|
| 分屏道路 | 复用单屏背景、资源较低 | 到边缘换屏，连续感弱 |
| 连续地图＋跟随镜头 | 自主逛路与十字路口转向连续 | 增加导航/相机/裁剪，需实机验证性能 |

用户明确选择连续大地图，原话见evidence/pet/campus_exploration_choice_20261028_user.txt。先实现一个有界校园和现有三室内，取消生产目的地菜单。AI选择矢量道路/建筑、固定路网和屏幕到世界坐标换算，避免新增大背景缓冲；图为示意校园。户外存档安全恢复路口、保留双区日志，格式2读旧1；此为新增场景的实现兼容处理，不改变专用区方案。最终性能与触摸由用户板端验证，不承诺未测帧率。
