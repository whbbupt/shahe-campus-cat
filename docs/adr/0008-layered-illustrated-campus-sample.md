# ADR-0008：分层插画校园局部样板

日期：2026-11-05。状态：用户选定路线，具体工程参数由AI执行。

| 方案 | 优点 | 代价 |
|---|---|---|
| 继续矢量绘制 | 小资源、易调整 | 精细材质和室内统一成本高，用户否决现有外观 |
| 整幅大插画 | 整体构图统一 | 局部修改、遮挡与连续地图维护困难 |
| 分块地面＋独立景物 | 局部迭代、深度排序、复用现有LVGL | 需素材管线和性能验证 |
| 规则图块地图 | 复用和扩展容易 | 素材网格约束/拼接感需处理 |

用户明确选择第三种，再在精致插画与精致像素对照中选择左侧插画，并认可先做教学楼前＋路口样板。证据见evidence/pet/campus_art_choice_20261105_user.txt。不将此选择扩大为整个校园立即重绘或新版实机认可。

沿用C/RT-Thread/LVGL，RGB565地面切块、RGB565A8建筑和树、统一脚底锚点与遮挡，现有室内/猫保留。向北增加180像素展示范围供建筑立面，原路网/存档不改。精确参数/配色/字体/标志性元素见design-contract.json。新增图片只存ROM，不增加运行时解码/文件系统。最终板端性能未知，单独TC-165，软件验证不能替代实物。
