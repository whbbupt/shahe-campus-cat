# ADR-0012 养成为主，穿插短小游戏

日期：2026-11-07。状态：用户确认方向，AI落实首批玩法。

用户认为现有玩法单一，明确选择“我倾向于养成为主，穿插短小游戏”。此前对比过养成主线与短小游戏穿插的安排，用户选择决定主次。本批按已有校园活动追加手账进度，教室加入可选记忆题；不将三轮长度、贴纸样式和具体目标写成用户亲自指定。

备选：把小游戏作为主要循环，以分数与挑战推动游玩；或以照料、校园活动和长期收集为主，小游戏提供短暂变化。采用后者。三个愿望完成后主动领贴纸翻页，没有每日清零或错过处罚。手账轮换三组愿望，沿用已有吃饭、上课、休息、锻炼、写代码、摸摸与图书馆旁散步。

记忆题先展示再输入，三轮长度为 3、4、5，没有输入倒计时。成功最多加 3 点心情、计一次成功，成功后冷却 60 秒；失败、取消无数值惩罚，可重试。正常上课也完成学习愿望，小游戏为可选路径。

存档使用格式 4，压缩七项冷却为 16 位毫秒，保留 64 字节记录、双区追加与驱动；读取旧格式 1 至 3。手账页、贴纸、成功次数和进度整体保存。未结束小游戏不保存，不在重启时补发奖励。具体编码由 AI 在现有架构边界内实现。对应 REQ-185 至 REQ-187、TC-192 至 TC-196。
