# 沙河全图 v0.9.0

[北邮沙河校区平面图](https://welcome.bupt.edu.cn/info/1003/1173.htm)为相对方位依据。北向保持朝上，户外坐标 1400×1300。距离按手表玩法压缩，局部支路和建筑外形为绘本化处理。

| 分区 | 主要走法与景物 |
| --- | --- |
| 北侧 | 北缘横路、研究区弧线、北区中部连廊、北园。规划用地以浅围栏和草地表现。 |
| 西侧 | 鸿雁路西门、现有运动场、雁北园，国脉西路通往雁南园和西南门。 |
| 中部 | 鸿雁路与国脉路交叉，向北沿图书馆和学生活动中心两侧通过，向南串联教学区、公教楼和水景。 |
| 东侧 | 校园东侧南北连接、智慧教学与工程教学片区。 |
| 南侧 | 南段横路通学生餐厅、南门及理学教学一带；南缘路连接西南门和东段。 |

三处可进入场景为雁北园宿舍、教综楼教室、学生餐厅。它们的室外节点随核心路网平移至 (455,580)、(1020,750)、(625,1110)。鸿雁路与国脉路的 (800,690) 为户外重启点。学生活动中心本轮为地图地标。

`src/pet_shahe_roads.inc` 统一维护道路坐标。模型将点击投影到道路，素材生成器用相同边生成纹理。旧版户外档继续恢复交叉口节点 0，室内节点沿用。

更新：v0.10.0 在学生活动中心门旁接通健身房，室外入口坐标为 (741,640)。
