# 沙河校园小猫 v0.16.1：每日饭钱

当前保留小游戏赚币、付费用餐/点心/外卖和三件固定布置，新增商店签到。每天领取6金币，正好够一份食堂套餐；奖励数额为AI初稿，用户新增了每日签到方向。漏签不罚、不补领、不计算连续签到。

## 怎样领取

1. 沿用CodeKit Download更新到v0.16.1，无需另重复执行bat；完整产物仍在project/build_sf32lb52-lchspi-ulp_hcpu，不全片擦除。
2. 连接iPhone完成校时，再打开“商店”。可信北京时间当天未领时按钮显示“签到 +6”，领取后显示“今日已领”。没有有效时间时显示“先校时”；需要先叫醒/等待走路动作结束才能领。
3. 按北京时间00:00进入新一天后可再领。金币和签到日期一起保存；等状态页“已保存，重启可恢复”后再复位，当天不会再发。
4. 余额满9999时先消费再领，接近上限时只增加剩余可容纳的金币，浮动提示显示实际增量。最近已领日期比当前日期晚时显示“校准日期”，不会因为回拨又领一次；修正到真实日期后，真实日期超过上次已领日期才能再领。

这是离线设备时钟规则，不提供服务器时间验真；不把手动调到未来的日期当作真实跨日实测。手机断开后若RTC仍有效可签到；失时先重新校准。不保存每秒日历。
