# 沙河校园首批路线底稿

参考[北邮迎新网校区平面图](https://welcome.bupt.edu.cn/info/1003/1173.htm)及[图像原件](https://welcome.bupt.edu.cn/__local/7/EA/DC/B8E3CB1AF04C4D55DA4E6C15749_25514C4B_53183.jpg)。图面署名北邮人团队，标为 2026.08。以图面北在上，坐标为游戏压缩坐标。

```text
                            北 ↑
              雁北园
              门(225,280)
       (155,280)──┘
            │                国脉路
       (155,390)──────────(570,390)──────(790,390)  鸿雁路
                              │                │
                              │            门(790,450) 教综楼北侧
                          (570,640)
                              │
       南段支路 (395,760)─(570,760)
                    │
              门(395,810)
                学生餐厅
````

| 门 | 对照依据 | 游戏入口和返回点 |
| --- | --- | --- |
| 雁北园 | 南组团位于鸿雁路北、国脉西路东，2号楼西侧门标记 | 西侧路进入，(225,280) |
| 教综楼 | 教学实验综合楼位于鸿雁路南、国脉路东，北侧有门标记 | 鸿雁路南向短接，(790,450) |
| 学生餐厅 | 位于国脉路南段西侧，图上没有清晰餐厅门标记 | 游戏取北侧临路门，(395,810)，实际门位待现场核实 |

鸿雁路与国脉路交叉口 (570,390) 是户外重启安全点。缩短步行尺度，保留主要方向和折返。首批仅绘制这段连接路及周边景物。

素材初估为三张室内 RGB565 底图 1,053,000 字节，三个裁紧前景约 45 KiB，室外预估 300 KiB 以内（复用独立楼、树等素材）。替换旧底图和旧校园样板时，以链接输出为准。保留既有猫帧、状态字号与存档结构。
