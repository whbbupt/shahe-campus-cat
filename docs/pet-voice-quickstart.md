# 沙河校园小猫 v0.20.8 语音试用

## 下载

1. 用 USB 连黄山派的 USB-to-UART 口。打开小猫工程的 `project`，在 CodeKit 选 `sf32lb52-lchspi-ulp` 并点 **Download**。使用常规下载，关闭全片擦除选项。
2. 下载后串口波特率用 `1000000`。确认启动行出现 `[pet] v0.20.8 boot ok`、`[pet:VOICE] worker ready stack=40960 bytes` 和 `[pet:KEY2] selftest PASS`。

## 试聊

1. 手机打开蓝牙与网络共享。Android 开启「蓝牙网络共享」，iPhone 开启「个人热点」的「允许其他人加入」。手表点左上方「语音」。
2. 保持手表在语音页，在手机的蓝牙列表搜索 `ShaheCat Talk`。两边的配对码一致时，在手表点「配对码相同」，并在手机上确认。配对失败后留在语音页，等待手表重新开启搜索。BLE 校时配对可以保留。
3. 第一次若显示小智绑定码，到小智控制台添加设备。绑定后回手表点「已绑定，重试」。在小智控制台按账号可选项配置小猫的模型、人设和音色。 [小智控制台](https://xiaozhi.me/console/)
4. 看到「我在听」后，按住「按住说话」说一句，松手发送。听完再追问一次，例如先问「讲个校园笑话」，再说「讲短一点」。试播报中点「停止」，然后按「返回」回到校园。
5. 在校园或室内长按实体 KEY2 约 0.7 秒也能打开语音页。语音页短按 KEY2 循环切换静音（0/3）、中档和高档，音量条两秒后收起。开机默认中档，播报中也能调节。

请记录三轮是否都听到回答、追问能否接住上一轮，以及从松手到开口的大致时间。若录音后没收到回复，回传松手后的 `[pet:VOICE] record sent frames=` 或错误日志。搜不到设备时回传 `Local device name` 和 `scan mode`，配对失败时回传 `classic pair result`。请遮挡小智绑定码和手机蓝牙配对码。

如果已经连接蓝牙热点，但语音页显示「检查共享网络后重试」，点一次「重试」，回传 `[pet:VOICE] cloud phase=` 开头的所有行。该行给出失败阶段、步骤和数值错误码。

## 地址与回退

本版使用小猫工程原有的三镜像下载布局，仍读格式 12。主程序从 `0x12020000` 写入，下载镜像及其 4 KiB 向上取整范围避开 `0x12DA4000` 的 BLE 数据区和 `0x12DA8000` 的宠物存档区。常规方式可回刷 v0.20.0 或 v0.19.3。独立小智示例的测试包采用另一套 Flash 布局，只适合备用板。
