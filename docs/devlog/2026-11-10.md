## 遇到的问题与解决

> 报错/卡点 → 排查过程 → 根因 → 解决办法。没有就写“无”。重要的问题同步登记到 `06-风险与问题台账.md`。

- **`.git` 缺失**：工作区只有源码树，课程最看重的提交历史无法追溯。先确认不是隐藏目录，再检查同级 zip（不含 `.git`），最后用 `git ls-remote` 找到公开仓库并克隆；对比 blob/worktree 后恢复，保留原克隆作备份。未伪造任何提交。
- **本机没有 SiFli SDK/scons/arm-none-eabi-gcc**：`check_env.py` 三项缺失，目标构建无法执行。改用 WSL gcc 做主机逻辑/存档/BLE 回归，并在文档与 manifest 明确“未构建、未烧录”，不把主机通过写成固件通过。
- **Windows 应用控制策略拦截 zig 生成的主机测试程序**：`WinError 4551`，同一源码换 flag/改名仍被拦。根因是环境策略而非测试失败；改用 WSL Ubuntu 的 gcc 执行，保留该环境弯路记录。
- **首次图鉴自检 FAIL**：第二份餐请求返回冷却/已满——第一份餐后仍有 2 秒 `PW_EAT` 冷却，且土豆牛肉饭把饱食推到 100。测试夹具补 `pw_advance(2100)` 并重置饱食后通过，产品判据未放宽。
- **首次存档自检两条 FAIL**：`campus-safe-restore` 与 `challenge-life...` 仍断言 `s.saved[4]==10`，格式升 11 后过期。改为断言 `PS_SCHEMA` 后通过，旧失败保留在 04。
- **图鉴解锁时机**：最初把置位放在 `settle()`，但堂食在 `begin()` 就结算，会在“刚开始吃”时解锁；改为 `finish()`，取消/未吃完不信。该设计取舍写入 ADR-0019 与 02。
