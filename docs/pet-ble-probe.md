# 沙河校园小猫 v0.12.1：iPhone 蓝牙连接测试

本版基于 v0.12.0，保留校园、四个室内、手账、记忆题、声音和原存档。只增加 BLE 连接探针，尚不提供校时、现实作息、手机端养成界面或新小游戏。软件检查和构建通过不等于真实蓝牙通过。

## 1. 先确认固件

原 v0.12.0 没有小猫 BLE 服务，LightBlue 扫描不到是正常的。使用这次工程构建产物后，状态页版本应显示 `v0.12.1-bletest`。

可以沿用 VS Code/CodeKit 的 Download，对应工程 `D:/project/sifli/course_starter/project`，板型 `sf32lb52-lchspi-ulp`，输出 `build_sf32lb52-lchspi-ulp_hcpu`。下载工具沿用现有正确串口；不猜新的端口号。不把运行 bat 当成 Download 后的第二个必做步骤。

本包 firmware/ 保留完整下载配置与 main、bootloader、ftab 三镜像。普通下载不含存档区域镜像；不要选全片擦除，否则会清档。只更换 main 文件不能代表完整下载配置已核对。

## 2. iPhone 连接

1. 在 App Store 安装 LightBlue，打开 iPhone 蓝牙；首次打开应用时允许蓝牙访问。
2. 板端启动后，在 LightBlue 的附近设备列表中扫描，寻找 `ShaheCat-` 加六位字符的设备。地址获取失败时名称退回 `ShaheCat`。
3. 点设备进入连接。无需先在 iPhone 系统设置中完成配对；本探针也不需要个人热点或网络。
4. 展开自定义服务，UUID 为 `8A7C0000-2F73-4F25-9A4D-534841484543`。
5. 读取信息特征 `8A7C0001-2F73-4F25-9A4D-534841484543`，按 UTF-8/ASCII 查看，内容应包含 `ShaheCat 0.12.1-bletest BLE probe`。

如果本次只想先确认能否连上，做到这里就可以先回传截图。扫描到名字不等于已经连接；读到本版信息能进一步确认连接的是这块板和这版固件。

## 3. 双向数据（连接成功后可继续）

1. 打开可读写测试特征 `8A7C0002-2F73-4F25-9A4D-534841484543`。
2. 点 Read，初值为 `READY`。
3. 将数据格式切为 UTF-8/ASCII，写入大写 `PING`，不要加空格或换行；若使用 Hex，四字节为 `50 49 4E 47`。
4. 再点 Read，应得到 `PONG`（Hex `50 4F 4E 47`）。本版没有通知特征，不用订阅通知。
5. 在 LightBlue 中断开，再扫描并重连，测试值应恢复 `READY`。

其他文本、长度错误、非零写偏移会被拒绝。测试值只在 RAM 内，不能修改小猫数值、存档或RTC。

## 4. 保留真实结果

TC-214尚未执行。请回传 LightBlue 的已连接/版本信息截图；若做了双向测试，再附 PONG 截图。保留失败信息同样有用，不要求为了补齐旧训练重复外设测试。

如能采集串口，沿用1000000 baud，保留本版boot和`[pet:BLE]`原文。预期会有协议自检、广播结果、设备名、连接事件；这些只是预期，实际日志尚未取得。`[pet:BLE-TEST] protocol PASS`仅是RAM协议自检，不能单独证明无线连接成功。

连接期间也观察小猫走路、开门、声音和保存。新蓝牙实测不自动替代旧版存档/音频/屏幕未覆盖的验证。

## 5. 搜不到或连不上

先确认状态页是0.12.1-bletest、应用有蓝牙权限、没有另一台手机占用连接。启动约15秒仍未就绪时查看串口错误。重新扫描并尝试连接；出现事件队列故障日志时按提示重启板端再试。手机后台长期保持连接尚未验证。

## 6. 构建和容量

原 `python scripts/build_firmware.py -j4` 成功。ROM **7,415,548 / 8,388,608字节（88.40%）**，剩余 **973,060字节（约0.93MiB）**；静态RAM169,032字节，动态峰值和板端帧率未知。比v0.12.0增加149,589字节（约146KiB）。

main.bin为7,353,768字节，SHA-256：`604222F364A1D698166C7C0F9C368D9FCEB14A8DC52B672B1A1116ECC74EC966`。最终7条告警与v0.12.0相同，无新增；初次构建/主机错误与修复记录保留。

当前素材占用的主要部分：校园地面3,640,000字节；四房背景1,404,000；其他场景462,957；猫动画311,904；PCM音乐/音效609,280。图片是空间大头，C数组源文件的文本大小不能当固件占用。后续优先复用素材，压缩收益和解码性能另行验证；本轮没有删图、降画质、删音频或扩大分区。

分区与存档格式不变，下载地址仍为bootloader 0x12010000、main 0x12020000、ftab 0x12000000；BLE参数使用既有KVDB_BLE_REGION，不占PET_SAVE_REGION。旧v0.12.0完整15项产物已独立核验备份在课程输出的baseline-v0.12.0/。
