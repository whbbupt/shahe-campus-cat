# 沙河校园小猫：现实时间与校园作息方案

2026-11-08 · 基线v0.12.4-blefix · 实现前设计

用户最新选择“按现实时间作息，接入手机校时”。本文替代原48倍日程实施稿，历史决定保留于ADR-0014和Git；当前依据为[ADR-0015](adr/0015-real-time-campus.md)与[整体修改清单](pet-revision-plan.md)。新时钟和校时尚未进入当前固件。

## 1. 两种时间分别负责什么

| 时间 | 来源与用途 | 关机与校时 |
| --- | --- | --- |
| 现实日历 | RTC；首版按UTC+8显示日期、HH:mm，决定晨日暮夜、课程和餐点分类 | 有效RTC可继续走；失效提示重新校准，不能承诺所有断电条件都保时 |
| 实际运行时长 | 单调tick；走路、登床、动画、短游戏展示、PCM、外卖/冷却、在线双数值和保存节流 | 关机暂停；校时前后不跳动作、不补奖励、不补算离线饥饿 |

现实1分钟对应时钟1分钟。不再自动从“第1天07:00”开局，也不把显示日期与存档中的游戏进度混为一体。没有有效时间时显示待校准，原校园活动仍可用，时段惩罚暂不启用。

## 2. 手机怎样同步

当前iPhone连接和测试特征PING/PONG已确认，只验证了BLE数据通道。下一步在保留测试通道的同时新增独立校时项：手机发送当前时间，设备校验并设置RTC，再提供实际时刻和状态的回读。

首版实现需确定并写明日期/时区编码、字节长度、有效范围、错误码、请求排队与回读结果。LightBlue只作为手动测试端，提供可复制的时间编码辅助；连接本身不自动读取iPhone系统时钟。每次自动校时需要手机端程序主动发送时间，是另一项明确的集成工作，不能用“已连接”冒充“已同步”。

日期与时间一起设置，避免跨午夜只改时分秒；主线程处理RTC设置，SDK回调仅验证和转交。非法长度、偏移、年月日、闰日以及失败状态有测试；拒绝后不改变旧有效时间和宠物状态。前后调时只改变日历分类，不回放活动或结算。

## 3. 作息初稿

区间左闭右开。下表为AI实施参数，用户选定的是现实时间方向。

| 本地时间 | 氛围与活动 |
| --- | --- |
| 06:00–08:00 | 早晨；早餐、室内生活与去教室 |
| 08:00–12:00 | 白天；上课、课堂记忆题 |
| 12:00–14:00 | 白天；午饭、午休，教室可自习 |
| 14:00–17:00 | 白天；上课、锻炼和生活活动 |
| 17:00–19:00 | 傍晚；晚饭、散步 |
| 19:00–22:00 | 夜景；自习、小游戏、室内生活 |
| 22:00–23:00 | 提醒回宿舍准备睡觉，仍可自主活动 |
| 23:00–次日06:00 | 夜景；清醒标记困倦、可点床休息，仍有替代活动 |

三餐窗口06:00–09:00、11:00–14:00、17:00–20:00，其余简餐。教室上课只在两段课程时间，其余自习。到达开始时锁定活动类型，跨时段不重算。门路、吃饭和休息不因现实深夜被彻底锁住。

## 4. 睡眠与双数值

睡觉在宿舍点床触发，可主动唤醒，不让玩家为继续玩而现实等待几个小时。22:00提示、23:00后清醒显示困倦；先采用轻量反馈与温和收益调整，不新增体力/健康条或死亡机制。

饱食与心情仍为0–100，变化按实际在线时间。旧48倍方案的“每游戏小时”参数不再直接套用；新的消耗/恢复要用常见游玩时长模拟后确定，避免现实一天叠加原高频消耗导致全天饥饿。熬夜反馈仅在有效时间和在线活动下生效，不追罚离线时间，不靠反复校时刷收益。

睡眠/唤醒、无时钟、午夜、调时、数值上下界和一次结算分别检查。跨日不清手账、不发签到奖，短游戏保持可选，小奖励有冷却。

## 5. 显示与夜景

场景保留地点，增加数字钟与蓝牙小标识；状态页显示日期、是否校时、设备连接和音量。优先复用16/20px中文子集与已有控件，文字状态除颜色外还能直接阅读。

室内外用原图层调色：早晨柔暖、白天清爽、傍晚略暖、夜间蓝调与室内灯光感。只压暗场景，弹窗、音量按钮、门路与小猫保持可辨。不直接新增四套整幅底图；如因容量或特色需要换像素场景，按整体清单先做样板。

## 6. 保存与失时

宠物快照保留双数值、场景、睡眠、订单、手账和声音设置；时钟以设备当前有效RTC为准，不在恢复旧快照时倒拨日期。新设置和时间有效性如需保存，先明确布局、版本、迁移和降级写保护，读取旧格式1–5不丢已有养成。

复位、短暂断电、完全断电分别记录；RTC掉电失时后提示重新校准。没有实测不能保证电池/备用供电条件。持续走时不重置“稳定3秒”导致永不保存，也不能每秒写Flash。

## 7. 验证与实施入口

REQ-191、REQ-192、REQ-193、REQ-194、REQ-195已按现实时间更新；新增手机校时REQ-201、晚间休息REQ-202。原TC-203至TC-210同步改为新判据，旧判据没有执行成功记录，不伪造通过。校时重点TC-224/225，睡眠TC-226；完整新增顺序见pet-revision-plan.md。

实机需要核对手机写入后设备与回读一致、等待后走时、复位与断电表现、昼夜可见性、深夜替代活动、音量和游戏并行。构建必须低于8MiB，运行时内存和帧率另行实测。当前只是方案更新，未改固件或假称已同步现实时间。
