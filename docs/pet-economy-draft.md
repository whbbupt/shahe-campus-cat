# 小猫赚生活费：实现前草案

已确认方向：小游戏赚金币，用金币买食物与家具；手账/贴纸不再作为主循环。用户授权修改，先完成项目闭环再验收；暂不上传或交接。

闭环：玩小游戏→领取生活费→现买现吃/布置宿舍→保存→重启继续。第一版不增加复杂背包，食物付款后直接享用，家具购买后永久拥有。价格与奖励为AI待验证初稿：初始30金币，四小游戏通关10金币，失败完成2金币（不足5秒或主动退出不给，防反复点击刷奖励），共用原60秒奖励冷却；生活角落不产生金币，避免把免费互动变成刷币入口。基本餐6金币、点心3金币、外卖8金币；家具较贵作为长线目标，最高余额9999。

保障：饱食0仍能走路和玩小游戏；游戏失败也有保底收入，不能因没钱不能吃饭而永久卡住。错误点击/没钱/已满/忙碌/取消都不能扣钱；食堂与外卖各只在确实开始用餐/创建订单时扣一次；已付外卖取餐不再收费。原正餐/简餐、音量、现实时间、夜景、睡眠和路径保持。

家具方式待用户选择：A固定位置换款式（原动线不变、先完成闭环）；B自由摆放（需要动态避障、遮挡、存档坐标与新房间编辑流程）。在用户选择前不实施依赖该决定的布局代码。
