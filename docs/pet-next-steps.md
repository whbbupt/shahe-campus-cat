1. 现实时间批次已完成软件/构建，先取得TC-210/225新增板端结果；数字钟、手动校时、夜景、晚间休息与时段替代见新说明。
2. 已有容量、缓存、蓝牙状态及音量保留；在本批新夜景验证走动/触达和真实动态内存。
3. 当前主路径采用原生CTS自动读取，0004保留手动备用；是否成功以实际RTC核验及TC-240为准。
4. 昼夜、课程/餐点替代和睡眠已实现，数值在线推进、离线不追罚；按板端反馈调整参数。
5. 配餐/节奏/找物短游戏与室内生活互动、贴纸回看和需求提示，保持养成为主。
6. 原校园往返、保存/迁移、音频、BLE与UI合并回归，核对8MiB和产物哈希后交付。
7. 学生验证新增板端显示/声音/校时/玩法，真实结果追加至evidence及manifest。

## 边界

主世界采用现实24小时；手机校时需要手机主动发送当前时间，不由“已连接”自动完成。日历可随RTC继续，宠物业务关机暂停，完整断电保时待测。只有饱食和心情，保留夜间可玩的替代活动，不增加签到或死亡惩罚。

容量先优化，仍不足再按授权评估像素场景。像素风本身不保证省空间；必须比较编码、色深、分辨率、运行内存和实际构建。旧图和已测固件保留。

本轮新增内容属于实施计划与实现前登记。每个阶段完成后填入实际结果；尚未覆盖的板端判据保持待测，历史课程提交间隔和身份/证据缺口不伪造补齐。更早范围仍可在Git历史和原v0.7.1总计划中追溯。

自动校时补充：用户已同意ADR-0016系统CTS路线，v0.14.1连接后自动读取/转换/交给主线程核验，0004作备用；每连接只尝试一次完整流程，配对至多一次，断开继续RTC，建立连接仍由用户发起。不能把软件成功写成真实iPhone已通过。
