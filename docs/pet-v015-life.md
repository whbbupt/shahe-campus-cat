# 沙河校园小猫 v0.15.0：生活与短挑战

本版补齐当前总计划中的三个小游戏、室内小互动、贴纸回看和需求提示。软件与实际SDK LVGL主机验证已通过，最终板端验收未执行；此前v0.14.2配对与正确时间的用户确认继续有效。先统一验收，再上传GitHub并交接，见[接手说明](pet-handoff.md)。

## 新功能怎样使用

| 位置 | 入口 | 操作与结果 |
| --- | --- | --- |
| 宿舍 | 窗边“找物” | 看物品位置5秒，盖住后依次找三件物品；顺序以本局提示为准，总时限30秒 |
| 食堂 | 柜台旁“配餐” | 根据三轮订单选择米饭/青菜/鸡蛋/热汤，30秒内完成 |
| 健身房 | 窗边“节奏” | 每拍3秒，指针进入绿色时点一下；共6拍、至少命中4拍；同一拍多点不重复计数 |
| 教室 | 黑板“记忆题” | 保留原有三轮顺序记忆题 |
| 四间室内 | 盆栽/书架/餐后角落/器材旁“看看” | 小猫先沿路走过去，4秒后心情最多+2；分别为照看盆栽、整理书架、餐后小歇、放松伸展 |
| 手账 | “收藏 · n 枚” | 回看认真生活、校园探索、元气满满三类贴纸及获得条件；看收藏不会领奖 |
| 场景和状态页 | 小猫需求文字 | 饥饿、睡眠作息、低心情、外卖送达及愿望可领取提示；以实际状态为准 |

三种新小游戏成功心情最多+3，受100上限限制，界面显示实际增量；失败/取消不额外扣饱食或心情，正常在线消耗仍继续。右上角×随时退出；完成界面1.5秒自动返回。所有挑战（含原记忆题）和新生活互动共用60秒奖励冷却，成功开始计时；不是每个入口各有一份奖励。

现有食堂吃饭、健身、外卖、上床、写代码、照料和手账愿望保持。小游戏不提供基本食物，也不会代替真实的吃饭/锻炼愿望。新游戏成功次数复用原memory_wins存档字段累计，不清空原记录；生活互动不计为小游戏成功。

存档格式7、64字节双区、分区、驱动和节流不变。半局、生活动作和主动路径中延后保存；完成/退出后等状态页“已保存，重启可恢复”再复位。新挑战类型/半局只在RAM，重启不重放或领奖。旧v0.14.2可读同格式已完成的数值/冷却/累计记录；不会恢复新玩法的半局。

## 集中实机验收

沿用CodeKit Download，工程project/build_sf32lb52-lchspi-ulp_hcpu已有本版三个下载镜像及配置；不用为此再重复执行下载bat。不要全片擦除以免清档。串口1000000 baud，保留本次启动与实际操作日志。预期版本为v0.15.0，WORLD、SAVE、AUDIO等自检应按真实输出记录，不复制预期当实测。

以下项目未勾选即尚未取得本版结果。TC-229对应游戏，TC-231对应生活/收藏与保存；其余沿用旧用例的完整流程。可按自己的节奏一次走完，奖励冷却期间先走路或做普通活动。

- [ ] 宿舍：点地、桌椅、上床/叫醒、外卖和出门可用；找物看图、成功、错误和×退出操作正常。
- [ ] 校园→教室→食堂→健身房→宿舍：门能到达，转向不穿家具/草坪；顶部状态/手账受圆角影响情况和流畅度如实记录。
- [ ] 食堂配餐成功与错选、健身节奏绿色窗口与6拍判定可操作，结束回到原房间；奖励只一次，反复点/切入口不能绕过60秒冷却。
- [ ] 四个“看看”都先走近再互动；完成心情最多+2，没有穿家具或抢占原门/床/地面热点。
- [ ] 手账三愿望、领取贴纸、收藏未解锁/已收藏准确；反复查看不会重复领；低饱食/心情提示与实际数值吻合。
