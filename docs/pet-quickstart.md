# 沙河校园小猫上手指南

## 编译与烧录

使用黄山派 `sf32lb52-lchspi-ulp`、SiFli SDK v2.5.1 和 SiFli-SDK-CodeKit。先按 [T0 环境说明](../training/T0-环境与仓库.md)配好 SDK 与编译器。在已运行 SDK 导出脚本的终端中，从仓库根目录执行以下命令。

```text
python -m pip install -r requirements.txt
python scripts/check_env.py
python scripts/build_firmware.py
```

输出在 `project/build_sf32lb52-lchspi-ulp_hcpu/`。用 CodeKit 打开 `project/`，接入板子的 USB 转串口，选择 Download。启动后点右上角「状态」确认固件版本 v0.17.4。保留已有存档时请使用常规下载，避开全片擦除。

## 手机校时

| 手机 | 如何连接与校时 |
| --- | --- |
| iPhone | 在 LightBlue 中扫描并连接 `ShaheCat`，若出现系统配对提示就确认。连上后手表通过 iPhone 的蓝牙时间服务 CTS 自动读取时间。打开手表「状态」核对日期和时间。 |
| Android 8.0 及以上 | 安装「沙河小猫校时」。打开后点「寻找小猫」，按提示授权并点选 `ShaheCat`。App 会自动把手机时间发给手表，读回核对后显示「校时成功」。打包和权限说明见[安卓工具](../android-clock/README.md)。 |

手表按北京时间（UTC+8）显示。iPhone 表格列出已有实测的连接入口。安卓系统蓝牙配对后能否直接供手表读时，取决于手机是否提供 CTS。当前安卓工具使用 App 主动发送时间，端到端蓝牙联调登记在 TC-268。

如果扫描不到设备，先确认手表开机并靠近手机，再从此前连接的手机上断开。校时后，手表仍可在断开手机时继续走时。

## 校时后怎么玩

- 在食堂点座位，小猫坐稳后会弹出图文菜单。上下滑动选餐，确认时扣金币。
- 在宿舍点桌上手机叫外卖，送达后点门旁纸袋取餐。点「布置」可购买盆栽、挂画、书架，购买后会显示在宿舍。
- 在「状态」页领取当天饭钱，也可以玩小游戏赚金币。宵禁时仍可起床、在室内活动和从外面回宿舍。
- 需要复位时，先在状态页确认显示「已保存，重启可恢复」。详细菜单和价格见[校园生活](pet-v017-life.md)，界面入口见[固件 v0.17.4 说明](pet-v0174-hud.md)。
