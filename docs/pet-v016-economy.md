主循环已改为 **小游戏赚金币→购买食物/布置→保存→继续生活**。原顶部手账改为带金币图案的商店，生产界面不再要求完成愿望或收贴纸。四间室内、校园、音量/音乐、真实时钟、iPhone自动校时、昼夜/睡眠继续保留。当前仅软件与固件构建通过，尚无本版真实硬件结果。

## 生活费怎样赚、怎样花

| 内容 | 金币规则 | 实际效果 |
| --- | --- | --- |
| 初次游玩/旧版迁移 | 30金币，只初始化一次 | 旧生活数值/冷却/声音/RTC资格继承；0余额重新开机不会再送30 |
| 四个小游戏通关 | +10，余额上限9999 | 仍有原心情最多+3，界面显示实际金币和心情增量 |
| 游戏失败 | 参与至少5秒+2，不足5秒为0 | 不额外扣核心数值；退出不给奖励；已结算的通关/失败奖励不会再发 |
| 食堂套餐 | 6金币 | 到达座位、真正开始吃才扣一次，未到取消不扣；延续原饭点正餐/其他时段简餐 |
| 暖心点心 | 3金币 | 商店现买现吃，饱食最多+10、心情最多+1，满饱食不扣钱 |
| 宿舍外卖 | 8金币 | 在宿舍成功下单扣一次，30秒送达，取餐不再扣钱；旧版已有订单按原状态继承，不追补费用 |
| 窗台盆栽 | 40金币 | 买后永久拥有，出现在宿舍窗台 |
| 校园挂画 | 60金币 | 买后永久拥有，出现在宿舍墙面 |
| 桌面书架 | 80金币 | 买后永久拥有，出现在宿舍书桌 |

以上价格/奖励为AI初版参数，金币主方向和固定位置布置来自用户确认。没有充值、借贷、开箱或每日惩罚。暂不做背包，食物买后直接享用；家具可以免费收起/再摆上，没有卖回功能，不改变房间可走区域。

四小游戏所有有金币的结算共用原60秒冷却；立即重开、换房间、在结果页继续点都不能重复赚钱。生活角落只加心情，不发金币，保留原共享冷却。饱食为0仍能走路和玩小游戏，连续两次符合条件的失败保底就够买一份点心，因此资金耗尽不会永久卡死。初始30金币够体验几次正常用餐；家具作为逐步攒钱的目标。

食物页：食堂套餐需在食堂享用；点心在闲置时可买来吃；外卖需回宿舍订。布置页：购买后立即摆到宿舍，收起/摆上免费；睡眠、走路或忙碌时先等待，避免正在进行的动作被交易打断。缺钱、吃饱、未到正确房间、忙碌等按钮会说明原因，拒绝操作不收费。

## 保存和版本

金币、已购/已摆家具、游戏累计和生活状态一起保存在格式8的64字节双区记录。区域、驱动、节流仍沿用旧版；动作、主动路径和半局延后保存，交易后状态页先显示等待，待“已保存，重启可恢复”再正常复位。中途未保存即重启只恢复上次完整快照，奖励与扣费不会分开恢复。

读取旧格式1–7；旧手账数据不会被解释为金币，升级后初始30金币。旧v0.15.0/格式7固件无法直接读取新格式8，会保护写入；降级需要专门安排，不用整个旧工程覆盖当前项目，不要全片擦除。旧完整固件已按元数据备份。
