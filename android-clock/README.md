# 沙河小猫校时 v0.1.0

配合现有 v0.17.4 手表固件使用，适用于支持低功耗蓝牙的 Android 8.0 及以上手机。

1. 在手机上安装并打开「沙河小猫校时」，让手表开机并放在旁边。
2. 点「寻找小猫」并按系统提示授权。Android 12 及以上允许「附近设备」，Android 8 至 11 扫描需要位置权限，找不到手表时也请确认手机已开启定位。
3. 点选列表里的 `ShaheCat` 手表。连接后 App 会自动发送手机时间，校验读回结果并显示「校时成功」与手表确认的北京时间，然后断开连接。需要再次校时时，重新扫描并选择手表。
4. 首次实机验收时，对照手表与 App 的时间，再连一次确认可以重复校时。请保留成功提示和手表时间的照片或截图，失败时保留 App 的提示。

App 使用手机时钟，统一按北京时间（UTC+8）发送。若手表仍连着另一台手机，先从那台手机断开，再用安卓扫描。

## 从源码打包

需要 Python 3.8+、JDK 17、Android SDK Platform 34、Build Tools 36.0.0。从工程根目录运行。

```powershell
python android-clock/build.py --sdk "<Android SDK 目录>" --jdk "<JDK 目录>"
```

脚本先执行校时协议测试，再生成 `build/android-clock/shahe-clock.apk`，核对对齐、签名和应用清单。首次打包时会生成本地测试签名，同一电脑后续构建可复用该签名。
